# AI Guardian — Generative AI Documentation

**Company:** ServiceNow
**Product:** AI Guardian
**Role:** Senior Technical Writer
**Documentation:** Generative AI safety, guardrails, configuration, and administration

## Project Overview

AI Guardian helps organizations add safety controls to generative AI interactions by evaluating prompts and responses against configured guardrails. Its capabilities include protection against offensive content and prompt injection attacks, sensitive topic filtering, and support for additional guardrail capabilities through Guardrail Service Providers.

As a Senior Technical Writer at ServiceNow, I contributed to the AI Guardian documentation set as the product and its capabilities evolved. My work included authoring new documentation from scratch and substantially updating existing topics to incorporate product changes, improve technical accuracy, address documentation feedback, and strengthen the overall structure, consistency, voice, tone, and usability of the content.

My work covered both conceptual and task-based documentation, including content that helps administrators understand AI guardrail capabilities and configure guardrail services for generative AI interactions.
